Estructura del sitio web

Flujo de trabajo Git

main ──── código estable (producción)
│
├── dev ──── HTML + CSS base
│
└── diseño ──── mejoras visuales
│
└── PR → revisión → merge → main

Pull Request y revisión

  • PR creado desde dev hacia main
  • Revisión de código por Carlos Ruiz (Integrador)
  • Comentarios sobre estructura HTML y accesibilidad
  • Aprobación antes del merge

Resolución de conflictos

  • Conflicto en index.html — etiqueta <title>
  • Rama dev: "EcoVerde | Conciencia Ambiental"
  • Rama diseño: "EcoVerde | T2U2 DWI"
  • Resolución: se mantuvo "EcoVerde | T2U2 DWI"

Conclusión

El proyecto cumple con los requisitos de ramas, commits descriptivos, PR con revisión y resolución de conflictos. El sitio EcoVerde es responsive y accesible.
